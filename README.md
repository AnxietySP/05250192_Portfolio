# Sonam Phuntsho — Portfolio

A personal portfolio showcasing my skills, projects, certificates and experience as a Diploma student in **Computer System & Network** at Jigme Namgyel Engineering College (JNEC), Bhutan 🇧🇹.

Built using HTML, CSS and JavaScript.

## Pages
- **Home** – Introduction and profile.
- **About** – Personal information and background.
- **Skills** – Technical skills and tools.
- **Certificates** – My certificates and achievements.
- **Projects** – Projects I've worked on.
- **Contact** – Social links and contact form.

## Features
- Modern copper-and-green design.
- Dark and light mode.
- Custom animated cursor.
- Interactive solar system animation.
- Floating navigation menu.
- Interactive robot assistant.
- Certificate image viewer.
- Responsive design for mobile and desktop.

## Projects
- **NestWell.Bt** – A web application project.
- **Task API** – A REST API built with JavaScript and Express.js.
- **Events Hub** – A website for discovering college events.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Customisation
- Edit `style.css` to change the design and colours.
- Edit `script.js` to update interactive features.
- Update HTML files to modify page content.
